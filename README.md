## 👨‍💻 About Me

I'm **Muhammad Moiz Latif**, a Computer Science graduate from **COMSATS University Islamabad**, building production-style full-stack applications across the **MERN** and **PERN** stacks.

I care about more than just making something "work" — **architecture, performance, UX, and maintainability** matter just as much as shipping the feature.

Currently focused on:

- ⚛️ Modern interfaces with **React & Next.js**
- 🟢 API and backend design with **Node.js & Express**
- 🔷 Type-safe applications with **TypeScript**
- ⚡ Real-time features via **WebSockets / Socket.io**
- 🗄️ **PostgreSQL, MongoDB & Redis** as the data layer
- 🐳 Deploying with **Docker & Kubernetes**
- 🏗️ Scalable architecture and distributed systems

> **I don't just want to build projects. I want to understand why they work.**
